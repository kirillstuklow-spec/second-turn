# ArenaBuilder 0.6.6

## Установка

1. Закрой Godot.
2. Распакуй архив в корень проекта рядом с `project.godot`.
3. Разреши объединить папки и заменить существующие файлы.
4. Открой проект в Godot 4.6.3 и дождись импорта.

## Запуск

Открой сцену:

`Scense/Tools/ArenaBuilder/arena_builder.tscn`

Запусти текущую сцену через F6.

## Сборка арены

### 1. Описание

Укажи уникальный технический ID, название и необязательное описание.

### 2. Клетки и задник

- Задник необязателен.
- Изображение должно заранее находиться внутри проекта и быть импортировано Godot.
- Выбери `CellVisualData` в палитре.
- ЛКМ рисует выбранной плиткой.
- ПКМ берёт плитку с клетки в палитру.
- Кнопка `Заполнить всё` заполняет весь каркас выбранной плиткой.
- После выбора `BiomeVisualData` можно заполнить каркас его стандартной клеткой.

Все 35 клеток должны иметь визуал. Иначе ArenaBuilder блокирует сохранение.

### 3. Зоны

Доступно шесть состояний:

- без зоны;
- расстановка игрока 1;
- своя зона игрока 1;
- нейтральная полоса;
- своя зона игрока 2;
- расстановка игрока 2.

ЛКМ назначает выбранную зону. ПКМ очищает зону клетки.

Для каждой стороны указывается вместимость от 1 до 6. Сохранение возможно только тогда, когда число размеченных клеток расстановки точно совпадает с вместимостью обеих сторон.

Кнопка `Стандартные 6 + 6` создаёт прежнюю схему: две колонки по три клетки для каждого игрока.

Остальные зоны необязательны и могут иметь любую форму.

### 4. Объекты

Режим объектов уже присутствует в интерфейсе и `ArenaData`, но пока заблокирован: `ArenaObjectData` ещё не создан. Это намеренный каркас следующего этапа, а не ошибка.

### 5. Проверка и сохранение

Нажми `Проверить`. Ошибки блокируют сохранение.

Новые арены сохраняются в:

`Resources/Arenas/Arenas/Created/`

Можно открыть существующую арену, изменить её и сохранить либо создать копию через `Сохранить как…`. Builder не перезаписывает чужой файл через `Сохранить как…`.

## Подключение к бою

Открой:

`Scense/Battle/battle_scene.tscn`

Выбери узел `BattleEngine` и назначь созданный ресурс в поле `arena_data`.

Задник, визуальные клетки и логические зоны загружаются настоящим боем. Объекты будут подключены после появления их Data/Runtime/View.

## Автоматические тесты

- `Scripts/Tests/ArenaBuilderSmokeTest.gd`
- `Scripts/Tests/ArenaRuntimeSmokeTest.gd`

Первый проверяет создание, рисование, валидацию, сохранение и повторную загрузку арены. Второй проверяет загрузку арены настоящим Runtime, задник, клетки, юнитов и движение.
