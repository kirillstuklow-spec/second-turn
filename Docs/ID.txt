# Ability IDs / Словарь идентификаторов способностей

Версия: Prototype 01

Этот документ фиксирует строковые ID, которые используются в AbilityData, UnitAbilityData и будущих Pipeline.

Главное правило:
- Не переименовывать ID без необходимости.
- Новые ID добавлять ниже.
- Старые ID не удалять, пока они используются в .tres-ресурсах.
- Писать только маленькими буквами.
- Использовать snake_case.
- Не использовать пробелы.


==================================================
1. ALGORITHM IDS
==================================================

Algorithm ID — это строка в AbilityData.algorithm_id.

Он говорит Pipeline, какой общий алгоритм нужно выполнить.


Текущие ID:

deal_damage
- Нанести урон цели.
- Используется для атакующих способностей.
- Для Prototype 01 это главный алгоритм.


Будущие возможные ID:

heal_target
- Восстановить здоровье цели.

summon_unit
- Создать юнита на выбранной клетке.

apply_effect
- Наложить эффект на цель.

move_unit
- Переместить юнита.

push_unit
- Оттолкнуть юнита.

pull_unit
- Притянуть юнита.


==================================================
2. TARGET RULE IDS
==================================================

Target Rule ID — это строка в AbilityData.target_rule_id.

Он говорит Pipeline, какую цель разрешено выбрать.


Текущие ID:

single_any_enemy
- Одна любая вражеская цель.
- Для Prototype 01 используется у дальнего выстрела.


Будущие возможные ID:

single_adjacent_enemy
- Одна соседняя вражеская цель.

single_any_ally
- Одна любая союзная цель.

single_adjacent_ally
- Одна соседняя союзная цель.

self
- Сам источник способности.

all_enemies
- Все вражеские юниты.

all_allies
- Все союзные юниты.

empty_cell
- Одна свободная клетка.

selected_cell
- Одна выбранная клетка.

area_radius
- Все цели в области вокруг выбранной точки.

line
- Все цели по линии.


==================================================
3. TRIGGER IDS
==================================================

Trigger ID — это строка в AbilityData.trigger_id.

Для активных способностей поле может быть пустым.

Текущие ID:

Пока для Prototype 01 не используются.


Будущие возможные ID:

turn_start
- В начале активации юнита.

turn_end
- В конце активации юнита.

damage_taken
- Когда юнит получил урон.

damage_dealt
- Когда юнит нанес урон.

unit_moved
- Когда юнит переместился.

unit_died
- Когда юнит погиб.

effect_applied
- Когда на объект был наложен эффект.


==================================================
4. PARAMETER IDS
==================================================

Parameter ID — это ключ в UnitAbilityData.parameters или AbilityData.default_parameters.

Параметры хранят индивидуальные числовые или текстовые значения способности.


Текущие ID для Prototype 01:

damage
- Базовый урон способности.
- Тип значения: int.
- Пример: damage = 3.

armor_penetration
- Бронебойность способности.
- Тип значения: int.
- Уменьшает armor цели перед проверкой брони.
- Пример: armor_penetration = 1.

keyword
- Ключевое слово атаки.
- Тип значения: String.
- Используется для проверки защит и иммунитетов.
- Пример: keyword = "physical".


Будущие возможные ID:

range
- Дальность способности.
- Тип значения: int.

radius
- Радиус области действия.
- Тип значения: int.

duration
- Длительность эффекта.
- Тип значения: int.

cooldown
- Кулдаун способности.
- Тип значения: int.

charges
- Количество зарядов способности.
- Тип значения: int.

heal
- Количество восстанавливаемого здоровья.
- Тип значения: int.

summon_unit
- Ссылка или ID призываемого юнита.
- Тип значения: Resource или String, уточнить позже.

effect_power
- Сила эффекта.
- Тип значения: int.


==================================================
5. CONDITION IDS
==================================================

Condition ID — это строка в AbilityData.default_conditions или UnitAbilityData.conditions.

Условия определяют, можно ли применить способность.


Текущие ID для Prototype 01:

target_must_be_alive
- Цель должна быть живой.

target_must_be_enemy
- Цель должна быть врагом источника способности.


Будущие возможные ID:

target_must_be_ally
- Цель должна быть союзником источника способности.

target_must_be_damaged
- Цель должна иметь HP ниже максимума.

target_cell_must_be_empty
- Целевая клетка должна быть пустой.

requires_line_of_sight
- Нужна линия видимости.

source_must_be_alive
- Источник способности должен быть живым.

source_must_have_resource
- Источник должен иметь нужный ресурс.


==================================================
6. KEYWORDS
==================================================

Keyword — это ключевое слово атаки, эффекта, юнита или свойства.

Для Prototype 01 keyword используется в атаке и сравнивается с defenses / immunities цели.


Текущие ID:

physical
- Физический урон.
- Используется в LongbowShot.


Будущие возможные ID:

fire
- Огонь.

poison
- Яд.

bleed
- Кровотечение.

holy
- Священное.

dark
- Темное.

magic
- Магическое.

flesh
- Плоть.

undead
- Нежить.

human
- Человек.

beast
- Зверь.
