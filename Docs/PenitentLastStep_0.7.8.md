# 0.7.8 — Кающийся и «Последний шаг»

## Карточка юнита

| Свойство | Кающийся |
|---|---|
| Роль | Слабый призываемый боец ближнего боя |
| Команда в тестовой сцене | Команда 2 |
| Инициатива | `45` |
| Скорость | `2` |
| Максимум HP | `4` |
| Броня | `0` |
| Защиты / иммунитеты | Нет |
| Активная способность | «Удар крюком» |
| Пассивная способность | «Последний шаг» |

Характеристики взяты из таблицы банд. Урон «Удара крюком» в исходной
таблице описан только как незначительный, поэтому значение `2` является
тестовым, а не балансным.

## Карточка «Удара крюком»

| Свойство | Значение |
|---|---|
| Категория | Активная атакующая способность |
| Режим | `ACTIVE` |
| Стоимость | `1 AP` |
| Цель | Один живой враг на соседней ортогональной клетке |
| Взаимодействие | `MELEE` |
| Источник | `PHYSICAL` |
| Урон | `2` — тестовое значение |
| Бронебойность | `0` |
| Иммунитеты | Проверяются: сначала `MELEE`, затем `PHYSICAL` |
| Защиты | Проверяются и расходуются: сначала `MELEE`, затем `PHYSICAL` |
| Броня | Проверяется по обычным правилам |
| Кулдаун / заряды | Нет |

## Карточка «Последнего шага»

| Свойство | Значение |
|---|---|
| Категория | Пассивная триггерная способность |
| Режим | `TRIGGERED` |
| Триггер | `DEATH_CONFIRMED` владельца |
| Момент | После окна предотвращения смерти и освобождения клетки |
| Решение | Обязательный выбор игроком, если есть допустимая цель |
| Допустимая цель | Любой живой враг, ортогонально соседний с местом смерти |
| Если целей нет | Реакция автоматически пропускается |
| Ответ | Бесплатное применение того же плана «Удара крюком» |
| Источник ответа | Погибший Кающийся; временно не оживает |
| Стоимость | `0 AP` |
| Взаимодействие / источник | `MELEE + PHYSICAL` |
| Урон / бронебойность | `2 / 0` — общий план с «Ударом крюком» |
| Иммунитеты, защиты, броня | Проверяются по обычным правилам атаки |
| Отмена правой кнопкой | Запрещена: это обязательное боевое решение |
| Победа | Проверяется только после завершения всей посмертной цепочки |
| Глубина реакции | Учитывается в общем лимите `10` |

## Контракт смерти и решения

1. Смертельный урон переводит Runtime в `DEATH_PENDING`; HP становится `0`,
   обычные реакции, требующие живого владельца, больше не запускаются.
2. После стабилизации обычных реакций `DeathResolver` либо видит спасённого
   юнита, либо переводит его в `DEAD`.
3. При подтверждении смерти клетка освобождается, эффекты носителя удаляются,
   а `CombatEventLog` публикует `DEATH_CONFIRMED` с сохранённой клеткой гибели.
4. «Последний шаг» формирует `PendingDecision`. Пока решение существует,
   другие команды боя отклоняются.
5. Выбор приходит через `CommandDispatcher` и `DecisionPipeline`, после чего
   продолжается исходная очередь реакций.
6. Если выбор возник во время окончания активации, `TurnPipeline` продолжает
   её только после разрешения всей цепочки решений.

UI не выбирает цель самостоятельно: он только подсвечивает клетки из
`PendingDecision` и отправляет выбранный вариант как команду.

## Ручная проверка тестовой сцены

По умолчанию в сцене находятся Белый брат команды 1 и Кающийся команды 2.

1. Сведите юнитов на соседние клетки.
2. Белым братом примените `Melee Strike` к Кающемуся.
3. Кающийся получает смертельный урон, исчезает с клетки, а допустимые враги
   подсвечиваются как цели «Последнего шага».
4. Нажмите на Белого брата.
5. Он получает `2` физического урона, если удар не заблокировали защита,
   иммунитет или броня.
6. Только после этого бой завершается победой команды 1.

Маркер успешного удара:

```text
hook_strike_damage | applied | requested: 2 | applied: 2
```

Если рядом с местом гибели нет врагов, выбора не появляется и бой сразу
переходит к проверке победы.
