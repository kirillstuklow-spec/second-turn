# UnitBuilder 0.6

## Результат версии

Версия 0.6 добавляет законченный маршрут создания юнита:

`UnitBuilder → UnitData.tres → UnitRuntime → UnitView → бой`

Новый юнит создаётся без редактирования GDScript. Его можно сохранить,
назначить существующему тестовому бою через Inspector и сразу проверить.

## Как открыть UnitBuilder

1. Открой проект в Godot 4.6.3.
2. В FileSystem найди:
   `Scense/Tools/UnitBuilder/unit_builder.tscn`.
3. Открой сцену двойным щелчком.
4. Запусти текущую сцену клавишей F6.

## Как создать юнита

1. На вкладке «Основное» заполни:
   - технический ID латиницей в формате `white_prophet`;
   - отображаемое имя;
   - характеристики;
   - защиты, иммунитеты и ключевые слова через запятую.
2. На вкладке «Способности» добавь существующие
   `UnitAbilityData.tres`.
3. На вкладке «Визуал» назначь:
   - портрет;
   - простую картинку на поле боя;
   - при необходимости готовые `SpriteFrames`.
4. Настрой масштаб и смещение, ориентируясь на предпросмотр клетки
   80×80.
5. Нажми «Проверить».
6. Исправь ошибки. Предупреждения не блокируют сохранение.
7. Нажми «Сохранить» или «Сохранить как…».

Новые ресурсы по умолчанию сохраняются в:

`Resources/Unit/Created/`

## Как подготовить изображения

1. Создай в проекте удобную папку, например:
   `Assets/Units/MyUnit/`.
2. Скопируй туда PNG, JPG, WEBP или SVG.
3. Дождись, пока Godot импортирует изображения.
4. После этого выбери их в UnitBuilder.

Для простой заглушки достаточно одного PNG. Если назначена
idle-анимация, она имеет приоритет над простой картинкой.

## Как поставить созданного юнита в тестовый бой

1. Открой `Scense/Battle/battle_scene.tscn`.
2. Выбери узел `BattleEngine`.
3. В Inspector замени один из тестовых ресурсов команды 1:
   - `archer_data`;
   - `second_player_unit_data`.
4. Назначь сохранённый `UnitData.tres`.
5. Запусти бой.

Юнит должен:

- появиться на поле с назначенной картинкой или idle-анимацией;
- показать портрет в нижней панели;
- использовать назначенные активные способности;
- перемещаться вместе со своим визуальным представлением;
- исчезнуть после смерти;
- использовать текстовую заглушку, если визуал не назначен.

## Повторное редактирование

Кнопка «Открыть» загружает существующий `UnitData`.

- «Сохранить» обновляет открытый ресурс.
- «Сохранить как…» создаёт отдельный ресурс.
- Для копии требуется новый уникальный технический ID.

## Ограничения текущего среза

- UnitBuilder подключает способности, но не создаёт их.
- Пассивные способности сохраняются, но Runtime их пока не исполняет.
- `idle` и `death` уже используются `UnitView`.
- `move`, `block` и `hit` сохраняются в `UnitVisualData`, но их игровые
  события будут подключены отдельным этапом.
- Builder не является EditorPlugin и запускается как обычная служебная
  сцена.
